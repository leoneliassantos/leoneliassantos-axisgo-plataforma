Ativar a reclassificação de contas do DRE

Cria as tabelas onde ficam guardadas a classificação das contas (grupo/subgrupo) e os grupos que você criar. Faz uma vez só, depois do SQL principal do DRE.

Passo a passo:

  1. Abra o Supabase: SQL Editor da Batux.
  2. Clique em Copiar o código SQL aqui em cima.
  3. Cole na área branca do editor (Ctrl+V).
  4. Clique em Run (ou Ctrl+Enter).
  5. Deve aparecer Success. No rows returned. Pronto! ✅

Depois disso, no DRE aparece o botão “Reclassificar contas” (para admin).
