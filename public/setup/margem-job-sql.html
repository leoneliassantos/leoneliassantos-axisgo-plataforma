Criar a base de Rentabilidade de Projetos no Supabase

Isso cria as tabelas do modulo Margem Job (base dos jobs + parametro da taxa do ganho tributario), seguras e so para o time da Batux. Pode rodar mesmo se ja tiver rodado antes.

Passo a passo:

  1. Clique em Copiar o codigo SQL acima.
  2. Abra o SQL Editor do Supabase (projeto da Batux).
  3. Cole (Ctrl+V) e clique em Run.
  4. Deve aparecer Success. No rows returned. Pronto - agora da para importar a planilha Margem Job e lancar jobs pela tela de Rentabilidade de Projetos.
