Criar a base de Faturamento no Supabase

Isso cria a tabela onde a base do Publi vai ficar guardada (segura, só para o time da Batux), com as funções de atualização por mês e de exclusão (por mês ou nota a nota). Pode rodar mesmo se já tiver rodado antes — é seguro e só atualiza as funções.

Passo a passo:

  1. Clique em Copiar o código SQL acima.
  2. Abra o SQL Editor do Supabase (projeto da Batux).
  3. Cole (Ctrl+V) e clique em Run.
  4. Deve aparecer Success. No rows returned. 🎉 Pronto — agora dá para subir a base do Publi pela tela de Faturamento.
